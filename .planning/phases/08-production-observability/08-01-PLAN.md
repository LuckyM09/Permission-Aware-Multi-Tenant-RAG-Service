## Objective
Harden VaultRAG for production-grade deployment:
1. **Multi-Stage Non-Root Docker Containers**:
   - `infra/docker/backend/Dockerfile.prod`: Multi-stage build with Gunicorn (`4 workers`, `2 threads`), non-root user `vaultrag` (UID 10001).
   - `infra/docker/frontend/Dockerfile.prod`: Next.js 14 standalone multi-stage build, non-root user `nextjs` (UID 10001).
   - Production Docker Compose configuration with dedicated Celery worker.
2. **Liveness & Readiness Probes**:
   - `/healthz`: Liveness check verifying web server responsiveness.
   - `/readyz`: Readiness check validating PostgreSQL connectivity, `pgvector` extension state, and Redis cache/broker availability.
3. **Security Headers & Cookie Hardening**:
   - HSTS (`max-age=31536000; includeSubDomains; preload`), `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`.
   - Content Security Policy (CSP).
   - `SESSION_COOKIE_SECURE = True`, `CSRF_COOKIE_SECURE = True`, `SESSION_COOKIE_SAMESITE = 'Lax'`.
4. **API Rate Limiting & Throttling**:
   - DRF rate limiting configured:
     - `anon`: 20/minute
     - `user`: 120/minute
     - `search`: 40/minute
     - `chat`: 20/minute
5. **Automated Quality & Verification Suite**:
   - Test suite verifying probes, security headers, and rate limiting.
