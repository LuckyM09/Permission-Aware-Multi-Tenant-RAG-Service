## Objective
Provide tenant administrators with full visibility and control over access policies:
1. **Tenant User & Role Management APIs**: List, update roles (`admin`, `member`, `viewer`), and remove tenant members with strict admin-only gates.
2. **Permission Group Management APIs**: Create, update, delete groups, and assign/remove tenant members to/from groups.
3. **Access Explorer Engine**: An authoritative simulation engine using `documents.permissions` that evaluates any tenant member's permissions against all tenant documents, producing exact rule breakdowns (`OWNER`, `TENANT_PUBLIC`, `GROUP_MEMBER: <name>`, `DENIED`).
4. **Interactive Admin Frontend**: A Next.js dashboard at `/admin` featuring Members, Groups, and the visual Access Explorer.
5. **Comprehensive Test Suite**: Verify 100% permission invariants, admin role checks, and zero data leakage.
